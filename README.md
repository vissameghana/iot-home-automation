# IoT-Based Home Automation System 🏠⚡

An IoT-based home automation system developed using ESP32 to control household appliances through mobile applications, voice assistants, and manual switches.

## 📌 Project Overview

This project focuses on developing a low-cost and scalable home automation system using the ESP32 microcontroller.

The system allows users to control household appliances such as lights and fans through:

- 📱 Mobile applications
- 🎙️ Google Assistant
- 🗣️ Amazon Alexa
- 🔘 Manual switches

The system also supports manual control when internet connectivity is unavailable.

## 🎯 Objectives

- Enable remote control of household appliances
- Reduce energy consumption and power wastage
- Provide both smart and manual control
- Develop a low-cost and user-friendly system
- Design an IoT-based home automation system using ESP32

## 🛠️ Hardware Components

- ESP32 Development Module
- 4-Channel Relay Module
- Manual Switches
- Jumper Wires
- Electrical Loads — Bulbs/Fan
- Power Supply

## 💻 Software & Platforms

- Arduino IDE
- ESP Rain Maker
- Google Assistant
- Amazon Alexa

## ⚙️ Working

The ESP32 acts as the central control unit and communicates with the IoT platform.

User commands from the mobile application or voice assistants are sent to the ESP32. The ESP32 then controls the connected appliances through the relay module.

Manual switches provide an additional control method, allowing the appliances to be operated even when internet connectivity is unavailable.

## 🔄 System Flow

**User Command → IoT Platform → ESP32 → Relay Module → Electrical Appliance**

## 📊 Project Outcome

The system successfully demonstrated control of household appliances through voice commands, mobile applications, and manual switches.

The project also demonstrated reliable manual operation during network failures and provided a practical implementation of IoT-based home automation.
